### Non-Technical Summary

This project explores how artificial intelligence can efficiently solve complex problems when the correct answer is unknown. Using optimisation techniques inspired by machine learning, the system learned to identify the best input combinations for eight hidden “black-box” functions while working with very limited feedback.  

Throughout 13 iterative rounds, the project combined statistical models, clustering, neural networks and pattern analysis to balance exploration of new possibilities with refinement of promising solutions. Over time, the system became more accurate and efficient, progressively identifying stable optimal regions.  

Beyond achieving competitive rankings, the project demonstrates how AI can support decision-making under uncertainty — a challenge common in areas such as engineering, finance, scientific experimentation and real-world machine learning systems.

## Section 1: Project Overview 

This GitHub repository is part of the documentation for the Bayesian Black-Box Optimization (BBO) capstone project, designed to replicate the NeurIPS 2020 competition. The competition challenges participants to solve optimization problems, commonly known as Black-Box functions, that mirror real-world scenarios in which the underlying process is unknown.

The BBO capstone project has two main objectives. First, to implement an adaptive optimization strategy for Black-Box functions through an iterative process, seeking to identify the vector X that maximizes each function. Second, developing decision-making skills with limited information generated by an unknown process, through an iterative process that constantly updates the information, potentially affecting the decision with each new iteration. 

Professionally, the BBO capstone project has helped me develop both technical and decision-making skills. However, in my case, the most relevant aspect is applying a decision-making process with limited information that will be updated as iterations progress, potentially modifying my previous decision.

## Section 2: Inputs and Outputs 

The project proposes eight synthetic Black-Box functions, each with a different input dimensionality (2D–8D). Each function receives a vector of values X and returns a scalar value. The main objective is to find the vector X that maximizes each Black-Box function.

### Input Format 

All inputs must be restricted to values 0 ≤ xi < 1, expressed in the following format: x1-x2-x3-...-xn, and specified to 6 decimal places:

- Function 6: [0.697910-0.990583-0.035622-0.974136-0.655285] 

### Output Format 

For each input X, the function returns a scalar output: y = f(X), which can be positive or negative:

- Function 6: -2.0390133791009304

## Section 3: Challenge Objectives 

Develop and implement a methodology to maximize the output of Black-Box functions by applying BO models. Scenarios of this type present a considerable number of constraints: 

- Unknown function structure 
- One query per function per iteration 
- Time-consuming and expensive testing 
- Non-stationarity, heteroscedastic, and noisy data 
- Increasing dimensionality 
- Computational costs. 

## Section 4: Technical Approach 

This methodology is based on the implementation of several complementary models, each with a well-defined purpose. 

### Bayesian Optimization (BO) 

BO is the core technique of the methodology, using Gaussian Processes (GP) as surrogate models in conjunction with two acquisition functions, Expected Improvement (EI) and Upper Confidence Bound (UCB), to guide the selection of new points that are likely to improve performance or reduce uncertainty. 

### Heteroscedastic Evolutionary Bayesian Optimization (HEBO) 

Although HEBO is one of the most advanced techniques for maximizing Black-Box functions, as it can model non-stationarity, heteroscedasticity, and data noise, we use it in our methodology only to explore new, promising regions. 

### Clustering 

Clustering is used to gain visibility into the data structure, primarily to understand the magnitude of the nearest-neighbor output and identify promising clusters.

### Support Vector Machines (SVM) 

Our implementation considers Linear SVM and RBF SVM to improve data visibility. By training these models, observations are labeled as high or low, allowing us to identify regions of high or low performance and evaluate whether new data points are located within promising areas, making exploration or exploitation decisions accordingly. 

The integration of different techniques results in a very robust combination, as it not only focuses on identifying the next point to be evaluated but also on gaining visibility into the function's behavior, enabling much better-informed decisions about expected results in each iteration. Essentially, this methodology enables the development of a robust and adaptable optimization strategy as information is updated.

## Section 6: Methodological Notes

### The dataset and model should be interpreted as part of a sequential decision-making process.

-	Data reflects an optimisation trajectory 
-	Model outputs require practitioner interpretation 
-	Strategy evolves based on: 
    - neighbourhood analysis 
    - clustering structure 
    - surrogate model behaviour 

### Limitations

-	Strong bias toward local exploitation 
-	Possible missed global optima 
-	Performance depends on initial exploration coverage 

## Section 7: Weekly Search Strategies. 

**Week 12:** The strategy was focused on exploiting the best points within the initial data, based entirely on heuristics. I used distance-based techniques to make the decision. 

**Week 13:** The strategy focused on exploiting promising areas identified by estimated clusters, with the highest estimated values concentrated there. Among the points estimated by the GP + EI, GP + UCB, and HEBO models, I selected the point closest to the cluster's centroid in the promising area, seeking a local maximum.

**Week 14:** With more information about each function, I revised the strategy, recognizing that the trade-off between exploitation and exploration needed to be handled individually and adaptively, as the information gained at each iteration could significantly alter the balance. Additionally, I began using a simple SVM to identify promising regions by classifying suggested observations estimated by the GP+EI, GP+UCB, and HEBO models.
